A library of shared composite actions and reusable workflows to keep CI consistent across projects rather than copy-pasted into each one. Some are tailored for TypeScript monorepos (Node + pnpm setup, lockfile validation, prerelease guards), while others are generic and composable (shell testing, build steps, generated-code drift checks).

See the [repo README](https://github.com/couimet/github-actions#readme) for the full catalog.
